## What I'm Focused On

**🛡️ Active Directory Security:** Enumerating and attacking AD environments — privilege escalation, lateral movement, and Kerberos abuse — while learning how to detect and defend against the same techniques.

**🌐 Web Exploitation:** Hunting and exploiting web vulnerabilities (RCE, injection, authentication flaws, insecure deserialization) and following real-world attack chains from entry point to impact.

**🐉 Offensive Tooling (Kali Linux):** Living in Kali — using and dissecting offensive and defensive security tools to understand modern threat landscapes.

**🐍 Python & Java Security Tooling:** Writing custom scripts to automate recon and exploitation, and modifying existing tools to fit specific lab scenarios.

**🤖 AI in Security:** Leveraging AI to accelerate research, tooling, and analysis across my security work.

> *On the side:* I occasionally build automations with **n8n** as a hobby 🔗, and I have an amateur interest in **AWS** cloud ☁️.
